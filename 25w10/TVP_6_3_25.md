1) multitasking vs paralelizace
  * paralelizace - v rámci času => součinné/současné zpracování
		      		   - on currency - real time (reálná) -> více jader
					                  	- apparent (zdánlivá) -> na jednom jádru s přepínáním -> context switching
      				   - zdánlivá - nejjednodušší příklad => operační systém - GNU+Linux
			    				  -> situace: jeden jednojádrový PC s několika uživateli pracujícími současně
					    			 jak funguje? D TIMER s nastaveným časovým <něco> do <něco> -> časový multiplex/round robin

                      1ms   1ms   1ms
								    |-----|-----|-----|...

      					 - context switch -> uživatel je nastaven jako proces
			      												 "jádro přepíná mezi procesy" -> z čeho se skládá proces? -> z přidělený sekce paměti
																					      																							-> vlastní obsahy všech registrů (včetně SREG, PC...)
						       jak vypadá to přepnutí?
									   - napsat obsahy všech registrů do přidělené sekce paměti; při 'shození' uživatele z procesoru
										 - obnovit obsahy všech registrů z paměti procesu při obnovení uživatele
								 - summary: round robin je softwarová "paralelizace" -> {multiprocessing; sdílení zdroje několika uživateli} -> zvýšení propustnosti -> paralelizace 

  * reálná paralelizace -> současné rozpracování - přes několik fází (RISC pipe)
	                      -> úplně nezávislé současné rozpracování s několika jádry
												   -> soustava? -> MCU více jader (128 jader)
													              -> cluster - MCU přes switch (neomezenej)
										    -> přepnutí - má režii (žere čas)
												   synchronizace - žere čas
													               - obsahuje neřešitlné problémy - hladovějící proces
																				                                - obědvající filozofové...
										    -> zásadní otázka s paralelizací
												   1) je problem řešitelný paralelizací - odpověď: někdy ano, někdy ne
													 ANO -> 2) co je vhodný algoritmus? - optimální podproblém?
													                                    - synchronizace paměti přístup
  * multitasking - round robin - zdánlivý multitasking

2) MCU & vložený systém
  * vložený systém -> jakékoliv zařízení řízený počítače
	                 -> výhody -> změna funkce zařízení vyžaduje nový SW [cena ↓]
	* konstrukce vloženého systému:
	  1) zpětnovazební smyčka - snímače, úprava signálu, řídící jednotka, vstup od uživatele, akční člen
		2) PID regulátor - P -> proporcionální
		                 - I -> integrační
										 - D -> derivační
